# Art Gallery - A sua galeria de arte
## O que é?
O ArtGallery é uma plataforma de curadoria e exposição de obras de arte digitais. Artistas podem cadastrar obras na plataforma, enquanto curadores organizam exposições temáticas e usuários podem visualizar, avaliar e pesquisar obras cadastradas. O sistema deve permitir o gerenciamento de diferentes tipos de obras digitais, cada uma contendo
características específicas, incentivando o uso de herança, sobrescrita e polimorfismo. O trabalho deverá ser implementado utilizando Java.

## Funcionalidades
Além disso, o sistema deve permitir:

1. Cadastro de obras; 
2. ​Ativação e desativação de obras;
3. Avaliações de usuários;​
4. ​Organização de exposições;
5. Consulta de obras mais populares;
6. ​Busca por artista;
7. Visualização de detalhes específicos de cada tipo de obra.

## Objetivos da implementação
O principal objetivo do trabalho é aplicar corretamente os conceitos de orientação a objetos em
Java, incluindo:
* Herança;
* Polimorfismo;
* Sobrescrita;
* Classes abstratas;
* Interfaces;
* Encapsulamento;
* Ligação tardia (late binding);
* Tratamento de exceções;
* Utilização de coleções Java.
